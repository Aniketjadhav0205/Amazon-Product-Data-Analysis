# Amazon Product Data Analysis

## Project Overview

This project focuses on cleaning and analyzing an Amazon product dataset using Python and Pandas.

The project includes data quality checks, data cleaning, product category analysis, rating analysis, and preparation of a cleaned dataset for further visualization and analysis.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Python
- CSV

## Data Cleaning

The following cleaning tasks were performed:

- Checked missing values
- Checked Product ID uniqueness
- Identified duplicate Product IDs
- Removed ₹ symbols and commas from price columns
- Converted discounted price and actual price into numeric values
- Removed percentage symbols from discount percentage
- Cleaned rating count values
- Converted ratings into numeric values
- Checked missing ratings
- Exported the cleaned dataset

## Analysis

The project includes:

- Dataset overview and descriptive statistics
- Number of products by category
- Average rating by category
- Category-level comparison of product ratings
